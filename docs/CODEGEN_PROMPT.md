# Implementation prompt for the code generator

Modify the **existing `timegrapher-stand` repository**, not a newly generated project. Before making changes, read these inputs in this order:

1. `AS_BUILT_ARCHITECTURE_SOURCE.md` — authoritative description of existing firmware behavior.
2. `IMPLEMENTATION_SPEC.md` (P3.0) — target behavior and acceptance tests for PCM1808.
3. The actual `platformio.ini`, `include/` and `src/` files, and relevant `docs/` and `tests/` files in the repository. Where actual source differs from the architecture summary, report the discrepancy and preserve the working behavior unless a P3.0 change explicitly requires otherwise.

## Objective

Add **two** PlatformIO environments (`pico2_pcm1808`, `kiwi_pcm1808`) using `AUDIO_SOURCE=PCM1808`, with PCM1808 master-mode I²S received on RP2350 PIO + DMA, mono PCM16 into the existing audio ring, and SCKI generated by **GP21 GPOUT0 from 150 MHz PLL_SYS** at nominal 12.288 MHz using `clock_gpio_init_int_frac16(...,12,0x3500)`. Keep both cores at 150 MHz. Fractional SCKI edge jitter is intentionally accepted for this bench prototype.

## Non-negotiable preservation

- PlatformIO / Arduino-Pico Earle Philhower / Adafruit TinyUSB + `-DUSE_TINYUSB` / `lib_archive = no`.
- Existing four build environments and board configs (Pico2 RP2350A GP26 ADC, Kiwi RP2350B GP40 ADC, Kiwi 2MB flash and Picoprobe).
- Existing composite USB CDC + one UAC2 mono 48k/16-bit recording interface. No new speaker, no audio stereo presentation, no forced removal of CDC.
- Existing `usb_audio.cpp` algorithm: exactly 48 samples once per millisecond into TinyUSB; `CFG_TUD_AUDIO_EP_IN_FLOW_CONTROL=1`; no new bursts or competing packet size control.
- Existing `audio_source` stream FSM, 8192-sample PCM16 ring with 480-sample prefill, hold-last-sample underrun handling, open/close/suspend reset, and GP25 LED.
- Existing looped 19,192-sample `tick-tock.wav` SYNTHETIC source and onboard ADC/DMA source. Preserve working software unless clearly necessary.
- `platformio.ini` `-DCFG_TUD_*` flags are the live TinyUSB configuration; `include/tusb_config.h` is only a mirror.

## Required output

Produce compilable source and headers, PIO assembly and a reproducibly generated `.pio.h`, PlatformIO envs, pure host-side conversion tests, wiring/clock documentation and real build evidence. Use a pair of ping-pong DMA buffers carrying **240 stereo frames each**, decode left signed 24-bit samples from 32-bit I²S slots and scale to signed PCM16, feed the ring from normal application context, not ISR. Keep both independent clock domains visible in diagnostics and measure ring occupancy drift under long recordings. Compile all six envs if the toolchain is available. Never invent hardware test success.

Report a concise list of changed files, exact command lines and pass/fail of each environment, known untested hardware risks, and any remaining blocker. Avoid migrating to Pico SDK CMake, adding runtime source switching, changing USB descriptors, or modifying PLL_SYS late during USB use.
